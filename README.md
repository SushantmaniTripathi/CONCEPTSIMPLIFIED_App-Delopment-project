Basic arithmetic operations (+, −, ×, ÷)

Clear (C) and backspace (⌫) functionalities

Real-time result display

Fully responsive design for all screen sizes

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript

📌 Project 2: University Attendance App

A web-based system for tracking and managing student attendance. This app simulates the flow for both students and faculty, including login, course tracking, and attendance overview.


🚀 Features

Separate login for Students and Faculty

Course-wise attendance management

View attendance records

Clean, dashboard-style UI


🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript

Backend: Python (Flask / Django)

Database: SQLite / JSON / CSV
